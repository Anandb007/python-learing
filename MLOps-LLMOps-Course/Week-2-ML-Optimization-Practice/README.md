All examples in Week 2 use **AWS and DevOps** scenarios:

- 🖥️ **EC2 Cost Prediction** — Predicting monthly compute costs
- ⚡ **Lambda Execution Time** — Predicting function runtime
- 🚀 **Deployment Success** — Classifying deployment outcomes
- 📊 **CloudWatch Metrics** — Predicting resource utilization
- 🔄 **CI/CD Pipeline** — Predicting build times
